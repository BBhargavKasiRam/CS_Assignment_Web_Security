About This Experiment

Blind OS Command Injection occurs when an application executes an operating system command using untrusted user input without directly returning the command output to the client.

In Time-Based Blind Injection, the attacker injects a command that introduces an intentional execution delay (e.g., 5 seconds). An observed delay in server response confirms that the injected command was executed by the shell.

Secure Mode implements strict allow-list input validation and avoids the shell using parameter-vector execution (shell=False), blocking any command injection attempt.
